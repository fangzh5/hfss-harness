# 交互确认和验证清单

从Gerber/Drill反向重建HFSS前使用本文件。建模前须核对叠层和材料语义的完整性与来源，复用已有授权和已核验输入。

## 建模前问题

按以下清单核对，仅对缺失或冲突字段简短提问，并等待依赖这些字段的工作：

1. 哪些文件是权威输入？
   - 铜层Gerber、闭合GKO/Profile板框、Drill、叠层说明、`fabrication.json`、KiCad/Altium工程或板厂预览。
2. 一共有多少铜层？从顶到底层名是什么？
   - 沿用输入包的层名并明确顶到底的顺序，层数不预设。
3. 每层铜厚是多少？
   - 确认是基铜还是成品铜。
4. 相邻铜层之间是什么介质？
   - 厚度、材料名、`Dk`、`tanD/Df`。
5. 介质应该建成完整板体，还是只建相邻铜层之间的 slab？
   - 按权威叠层/GKO保留真实介质区域；空腔或局部叠层需要匹配的执行器，不自动填满或压缩层间空间。
6. 有哪些过孔类型？
   - 每组确认钻孔直径、起始层、结束层、激光孔/盲埋孔/通孔。
7. 焊盘由 Gerber 铜图形定义即可，还是需要在 HFSS 中额外生成 via pad？
8. 哪些对象必须忽略？
   - 端口、空气盒、辐射边界、标签、尺寸、辅助曲线、构造线、评审图形。
9. 反向模型仅用于可视化，还是要对比 S 参数？
   - 可视化允许更多简化。
   - S参数对比需要明确导体近似/厚度/损耗、真实介质参数，并谨慎重建端口。

## PyAEDT 前计划审查

先读取`stackup.json`、可读叠层说明及已有确认记录，形成字段/值/来源/状态表。检查单位和Z基准、铜层顺序、每层厚度与Z跨度、材料引用、介质Dk/Df、Drill层对以及材料模型适用的频率/条件（如源材料已给出）。不能仅凭材料商品名编造电磁参数，也不能用Gerber层名推出厚度或统一材料。

缺失或冲突时，只汇总尚需用户补充的字段，例如：“已读取层序和各层厚度；还缺指定介质层的Dk/Df，请补充这两项。”已有权威输入可直接复用；无叠层文件但已有完整确认表不必再次索取文件。关键字段待答时只继续不依赖这些字段的检查，不启动依赖它们的CAM规划或CAD建模。回复后写入本次resolved stackup及来源记录，再用于建模和结果核验。

本流程的提问由skill执行者完成；CLI不会交互收集输入。`optimizer.fabrication.cam_import`读取当前`hfss-stackup-2`并按逐层材料检查，缺项返回needs_input；`cam_rebuild`使用相同叠层并在CAD启动前检查较窄的原生支持范围。旧统一介质CLI要求显式材料/Dk/Df，拒绝材料冲突/多材料实际建模；它的dry-run只说明旧几何计划可生成，不代表材料完整或可仿真。依据数据契约与特征选择入口，不把旧包或测试schema直接交给新入口。

向用户展示紧凑计划：

- 层表：铜层和介质层的 z 区间。
- 材料表：导体、介质、`Dk`、`tanD`、厚度。
- 过孔表：层对、钻孔、数量。
- 排除对象列表。
- 已知简化项。

输入完整且已有建模授权即可调用PyAEDT；没有授权或关键输入仍缺失时，不开始依赖它们的建模。

同一任务已有授权与权威数据持续有效，不重复要求确认。项目默认将copper/PEC过孔的模型直径用于金属化Drill，特别标注优先；仅测试该规则无需再收集镀层厚度。未给厚度时明确采用理想PEC孔壁等效，不伪造PTH实体工艺尺寸；有限损耗EM对比另需完整材料/端口/求解recipe。

## 建模后检查

模型创建后：

- 同一个反向工程只打开一个 AEDT 实例。
- 如果要对比S参数，核对导体模型、厚度、损耗与EM recipe一致。
- 检查介质材料和透明度。
- 检查层 z 顺序和总板厚。
- 检查过孔 z 跨度是否匹配层对。
- 检查板框、比例和原点。
- 回读实际GKO的闭合中心线；板框缺失或未支持时拒绝猜用铜包围盒。
- 用 Gerber Viewer 对照源 Gerber；有原始 HFSS 时再做结构对比。

## 差异定位

如果反向模型和原始 HFSS 不一致：

- 先比较对象摘要：数量、材料、bbox、z span、顶点 z 值。
- 检查原始对象是否把多个铜层合并在一个对象里。
- 确认 AEDT 手工修改是否已保存，还是只存在于当前打开会话。
- 区分有意简化和非预期几何丢失。
- 没解释清楚具体差异前，不要修改重建规则。
