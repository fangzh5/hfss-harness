# v0.2.0

0.2.0围绕HFSS模型的优化、扫参和单点验证，统一了执行、结果读取、评价和模型保存流程，同时加入过孔建模与PCB导出/重建工作流。

## 主要变化

- opt/sweep/val统一参数事务和案例恢复，结果校验包含variation、单位、频带覆盖与来源。
- sweep支持OAT/grid/explicit，val支持重新求解和只读已有结果；补充公共只读预检。
- best按搜索仿真间隔保存，最终独立复验导出；原工程和旧快照保持独立，缓存及保存复验单独计数。
- 沿路径创建过孔，导出铜层Gerber、介质GKO、Drill和叠层；根据明确叠层重建几何与材料。
- 提供hh-sim、hh-iter、hh-via、hh-export-pcb、hh-rebuild-pcb五项公开skills。
- wheel可用scaffold建立新工作目录，包含模板、标准模型和文档，拒绝覆盖现有文件。

## 安装与升级

源码使用 `uv sync --extra hfss --extra cmaes`，PCB工作流再加入 `--extra cam`；BO再加入 `--extra bo`。也可安装本Release的wheel并用 `python -m optimizer.scaffold <新目录>` 初始化。

旧项目先保留原配置和运行目录，再按[迁移说明](../migration-0.2.0.md)核对字段、相对路径、频带和会话设置。默认先运行标准单点验证。标准优化示例从已知达标点开始，可能很快结束，不代表新的搜索过程。

## 验证与已知范围

标准模型的验证/扫参/优化、周期best及独立重开、已有结果只读、端口跟随、远场和算法代表链路已实测。Python3.11–3.13完成干净安装检查；真实仿真环境为Windows/AEDT2023.2/PyAEDT0.18.1/COM/non-GUI。

当前仍为Alpha。远场采样峰值不等于连续角度全局最大值；PCB重建完成几何和材料，不自动恢复端口、边界和求解设置；复杂CAM特征及其他AEDT版本按当前支持范围使用。本版不新增组装或断点续跑。

完整变化见[更新日志](../../CHANGELOG.md)，使用方法见[README](../../README.md)。
