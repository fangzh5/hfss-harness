# 过孔规划与制造意图

0.2.0 开发中的过孔服务位于 `optimizer/modeling`。纯规划、工作副本安全创建、所有权替换和故障回滚已接入公共入口；直线及固定角度XY圆弧+直线已做真实CAD验收。旧脚本已委托安全入口，`--no-save`仅生成文件历史规划。其他曲线/平面与版本的实际验收范围见 `via-creation.md`，不能把纯规划支持视为全部CAD行为已验收。

## 模型语义

- `solid_pin`：仿真的实体导电柱，不自动产生加工钻孔。
- `plated_barrel`：明确的镀孔意图，必须给出起止层、成品孔径、镀层厚度；外半径须与孔径/镀层一致。实际空心孔壁几何、叠层核验、钻孔工具及工艺补偿由后续建模/制造服务落实，不能仅凭此标签宣称制造包可用。
- `CircularKeepout`：圆形 XY 避让区域，适用于整段 Z 挤出；按孔外半径、区域半径、净距共同判断。不会静默删除转角孔或移动孔位来绕开冲突。

`build_via_plan` 不启动 AEDT。输入明确的 polyline/变量快照、前缀、半径表达式、底面 Z、正高度和间距。它保留尺寸表达式，求值后检查有限性、物理净距和坐标范围，输出 `ViaPlan`。`geometry_source` 说明输入来源，规划函数本身不证明快照与未保存 GUI 一致；实际执行前仍须由会话服务核对。

## 路径支持范围

- 直线与 `AngularArc`，圆弧支持 AEDT 的 XY/YZ/ZX 主平面；遵循 PyAEDT 0.18.1 的坐标轴旋转顺序。其他曲线/倾斜弧面明确拒绝。
- 不依赖输入 edge 顺序；按端点连接排序，可反转 edge。分支、不连通或 closed 标记与几何不一致拒绝，不用猜测的连线补洞。
- 每段独立采样并保留端点/转角，共享端点去重；闭合终点不重复。`max` 约束沿段弧长的最大间隔，`min` 约束最小间隔。短段无法同时满足端点和最小间距时拒绝。
- 实际圆柱采用 Z 方向，底面 Z 来自 `z_start`，不是路径点 Z。会对投影后的真实 XY 布置检查全体孔间净距，垂直路径投影重合也会拒绝。
- 支持 mm/um/µm/nm/cm/m/mil/in、科学计数法、基本加减乘除、变量依赖和项目变量 `$name`；不执行任意 Python，不支持全部 AEDT 表达式语法。裸长度以 mm 解释，裸角度以 degree 解释。
- 输出数量上限为 10000，极小间距导致过量采样时在分配前拒绝。

## 记录与兼容

`ViaPlan` 包含确定性 SHA256、来源/变量快照摘要、实际中心、尺寸表达式、沿路径间距和精确段长。`write_via_plan_csv` 排他创建新 CSV，记录总路径长度、闭合信息、实际孔底 Z、原路径 Z、沿路径步长与相邻中心距离；不覆盖已有文件。

`scripts/create_vias_from_path_config.py` 的路径 helper 已改为委托公共模块，原 import 名称和 CLI 参数保留。旧 `write_points_csv` 兼容接口没有完整路径上下文，不作为新计划的弧长/闭合长度验收输出；新服务使用 `write_via_plan_csv`。

独立离线 fixture 覆盖圆弧、乱序/闭合/复合路径、单位/变量、坏维度、碰撞/避让、孔意图和 CSV，不依赖私人 runs 或真实工程。实时路径与文件历史一致性、表达式/材料/Solve Inside回读、所有权和事务由via_creation/via_paths及安全入口负责；加工钻孔/孔壁由制造流程单独解释与验收。
